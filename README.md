# Projeto
Nome: Wardrope  

Orientador: Edgar  

Integrantes: Mateus Melo Fernandes, Pedro Reis, Andrei, Pedro Maia, Antonio, Cauã, Samuel.

## Oportunidade
Vimos que se organizar no meio corporativo, realizar documentações manualmente acaba sendo desgastante pelos problemas de se localizar dificuldade em achar um repositório ou documento em meio a muitos arquivos e o gasto de tempo desnecessário de se organizar no meio das documentações e diretórios para poder criar ou exportar esses respectivos arquivos de documentação.

## Proposta

Nossa aplicação busca fornecer uma visão macro dos projetos de uma empresa para facilitar e agilizar as documentações, oferecendo a busca específica por documentos, compartilhamento e edição em tempo real dos documentos, além da exportação destes arquivos de documentação, sendo o nosso diferencial do Notion e do Obisidian que são especializados público comum (não empresas) de forma individual. nós especializamos no ambiente corporativo.

### Resumo

Buscamos criar um espaço onde funcionários e equipes possam criar projetos, estruturar documentos em hierarquias e manter todo o conhecimento organizado em um único lugar.

## Requisitos Funcionais

### 1. Autenticação e usuários

* RF01: O sistema deve permitir cadastro com e-mail e senha
* RF02: O sistema deve permitir que usuários realizem log in
* RF03: O sistema deve permitir que usuários desloguem
* RF04: O sistema deve permitir recuperação de senha via e-mail
* RF05: O sistema deve permitir alteração de dados cadastrais
* RF06: O sistema deve permitir controlar o acesso às funcionalidades de acordo com o nível de permissão do usuário

------------------------------
### 2. Empresas

* RF07: O sistema deve permitir o cadastro de uma empresa
* RF08: O sistema deve permitir o preenchimento dos dados cadastrais de uma empresa
* RF09: O sistema deve permitir a edição dos dados de uma empresa ou a exclusão de uma empresa

------------------------------
### 3. Notas e diretórios

* RF10: O sistema deve permitir a criação de notas
* RF11: O sistema deve permitir a exclusão de notas
* RF12: O sistema deve permitir a renomeação de notas
* RF13: O sistema deve permitir a criação de diretórios
* RF14: O sistema deve permitir a renomeação de diretórios
* RF15: O sistema deve permitir a exclusão de diretórios
* RF16: O sistema deve permitir a inserção de uma nota em um repositório
* RF17: O sistema deve permitir a retirada de uma nota de um repositório
